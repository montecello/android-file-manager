Android File Manager
====================

Transfer files between your Mac and an Android or MTP phone over USB.
No developer mode, no USB debugging, no extra software.


INSTALL  (30 seconds)
---------------------

1. Drag "Android File Manager" onto the Applications folder shown here.

2. Open your Applications folder and double-click the app.

3. The first launch shows a warning: macOS cannot verify apps from
   developers who have not paid Apple's yearly fee. This app is free and
   open source, so it has not been through that. To open it anyway:

      - Click "Done" (or "Cancel") on the warning.
      - Open System Settings > Privacy & Security.
      - Scroll down. There is a line about "Android File Manager"
        being blocked, with an "Open Anyway" button. Click it.
      - Confirm with your password or Touch ID.

   You only do this once. Every later launch just opens.

   On older macOS versions, right-clicking the app and choosing "Open"
   is enough on its own.


USING IT
--------

1. Plug the phone into the Mac with a USB cable.
2. On the phone, pick "File Transfer" or "MTP" when it asks what the
   cable is for. ("Charging only" will not work.)
3. Click "Connect Phone" in the app.
4. Your Mac's files are on the left, the phone's on the right. Select
   files and use the arrow buttons to move them either way.


IF THE PHONE DOES NOT APPEAR
----------------------------

- Make sure the phone is in "File Transfer" / MTP mode, not "Charging".
- Quit anything else that wants the phone: Android File Transfer,
  OpenMTP, MacDroid, Image Capture, Photos.
- Unplug, wait five seconds, plug back in, and pick File Transfer again.
- Some cables are charge-only. Try a different cable.

The full troubleshooting guide lives on the project page.
